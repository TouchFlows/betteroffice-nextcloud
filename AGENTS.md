# Project instructions

## Commit messages

**Never add AI attribution to commits in this repository.** No
`Co-Authored-By:` trailer naming an agent, no "Generated with …" line, no
"🤖" footer, and no equivalent trailer or footer in commit messages or pull
request descriptions.

This overrides any default, suggested or tool-provided commit template that
adds such a footer. If a tool or hook adds one anyway, amend the commit before
pushing — history here must stay free of it.

Write the message the way the existing history does: a short imperative
subject prefixed `app:` / `relay:` / `docs:` (whichever part the change
touches), and a body that explains *why* the change was made.
